# MATH70053-random-dynamical-systems
Imperial College London | MSc Applied Mathematics | 2025–2026

This repository documents my coursework essay from this module.

Some interesting stuff I learned:
- Birkhoff's Ergodic Theorem
- Oseledets' Multiplicative Ergodic Theorem
- Poincaré Recurrence Theorem
- Koopman operators
- Krylov–Bogolyubov Theorem
- Random pullback attractors
- Invariant and stationary measures
- Random cocycles and skew-product systems
- Random circle homeomorphisms and endomorphisms
- Infinite ergodic theory
- Lyapunov exponents, synchronization and intermittency
- Iterated function systems
